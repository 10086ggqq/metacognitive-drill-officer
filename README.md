# 元认知出题官（通用版） · Metacognitive Drill Officer

> 一个不教你新知识、只负责戳破"能力错觉"的出题检测 Skill。
> 用户只需要做两件事：**输入一个知识点**，**（可选）上传原题截图或文件**。

[English README](./README.en.md)

## 为什么需要它

学习中最危险的错觉是：**看懂了 = 掌握了**。能认出正确答案 ≠ 能独立推导；能默读定义 ≠ 能讲给别人听。这个 Skill 基于认知科学中的四个原理设计：

| 原理 | 对应机制 |
|------|----------|
| 熟悉 ≠ 掌握 | 全程禁止选择题，强制独立输出推导 |
| 识别 ≠ 回忆 | 主动回忆检测（STAGE 1）+ 费曼输出（STAGE 6） |
| 工作记忆有限 | 复杂题强制拆成 ≤3 个认知步骤（STAGE 2） |
| 元认知校准 | 每题采集"做对预估"，与实际表现逐题对照 |

## 工作流程

```
用户提供知识点 + 原题截图/文件
        │
        ▼
 题目转录与确认清单（看不清必问，禁止猜题）
        ▼
STAGE 0  信心度采集（0%–100%）
STAGE 1  主动回忆检测 ── 失败则要求重新学习，从本阶段重测
STAGE 2  拆块出题（≤3 步，追问每步依据）
STAGE 3  10 道原题 Q1–Q10（每题采集：输出 / 做对预估 / 预估错因 / 反馈）
STAGE 4  变式攻击题 Qx-Vn（不计入 10 道，每轮 ≥2 道）
STAGE 5  盲区定位题（动笔前预判错因）
STAGE 6  费曼输出题
STAGE 7  【强制反思关卡】逐题回顾 + 思考反思 + 做题技巧（≥3 条）+ 复评信心度
STAGE 8  100 分制防运气判定
         ├── ≥70 分 → STAGE 9
         └── <70 分 → 追加一组 10 道题（用户供题 / 原题新变式，可混合），重跑 7–8
STAGE 9  生成总结文档（.md + .pdf）：时间轴总表、首次 vs 末次输出对比、改进清单
```

### 评分构成（满分 100）

| 项目 | 分值 |
|------|------|
| 10 道原题独立做对率 | 40 |
| 变式题独立做对率 | 20（不足 2 道则并入原题项，原题权重升至 60） |
| 反思质量（诚实/具体/有可复用技巧） | 20 |
| 元认知校准（预估 vs 实际） | 10 |
| 费曼输出质量 | 10 |

## 安装与使用

将整个 `metacognitive-drill-officer/` 文件夹放入你的 Agent 的 skills 目录即可。

**用户侧**只需说一句话，例如：

> "检测我是否掌握了三角函数诱导公式"（可附上练习册截图）
> "quiz me on Python list comprehensions"

支持上传：图片截图/照片、PDF、Word、txt/md。
- 截图模糊、缺条件 → 出题官会追问，不会猜题；
- 题数 ≠ 10 → 让你选定或由它补足并标注；
- 只给知识点 → 它自行命制 10 道并说明考点分布。

## 学科适配

- **理科**（数理化生）：独立推导/计算，追问每步依据
- **语言/文科**：默写、造句、举例、辨析近义概念
- **编程**：手写代码、预测运行输出、说出复杂度依据
- **医学/法律**等高记忆学科：同样适用主动回忆 + 变式 + 费曼组合

## 常见问题

**Q：判定不通过会怎样？**
明确告知"低于 70 分说明你可能只是侥幸"，然后追加一组 10 道新题（你供题或它改新变式），直到通过或你主动终止。

**Q：PDF 生成失败怎么办？**
先输出完整 Markdown 全文并提示你手动导出 PDF，内容不会因此省略。

**Q：它会给我答案吗？**
不会。它的职责是暴露盲区，不是讲解知识。
